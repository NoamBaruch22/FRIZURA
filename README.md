# FRIZURA - מערכת ניהול תורים והנה"ח למספרות בוטיק

ברוכים הבאים ל-**FRIZURA**!  
מערכת חכמה, מודרנית ואלגנטית שנועדה לנהל את כלל הפעילות היומיומית של מספרות בוטיק. המערכת מספקת פתרון הוליסטי מקיף המשלב ניהול לקוחות, קביעת תורים, ניהול פניות (לידים), מעקב היסטוריית טיפולים והפקת חשבוניות. 

## 🌟 הפיצ'רים המרכזיים במערכת

- **מניעת קביעת תורים חופפים:** המערכת בודקת באופן אוטומטי זמינות ומונעת קביעת תורים באותה השעה או חפיפה בשעות הפעילות.
- **מחיקה רכה (Soft Delete) ושמירת היסטוריה:** במקום למחוק נתונים לנצח, לקוחות ותורים "מחוקים" נשמרים כארכיון מוסתר לצורך שחזור ועיון. בעזרת מנגנון טריגרים חכם, מחיקת לקוח מסתירה אוטומטית גם את כל תוריו העתידיים.
- **מודול ניהול לידים (CRM):** ניהול לקוחות פוטנציאליים (לידים), כולל מעקב סטטוס (בטיפול, לא מעוניין, וכו'). בלחיצת כפתור ניתן להמיר ליד שהבשיל ל"לקוח משלם" ולהעבירו למאגר הלקוחות המרכזי.
- **הפקת חשבוניות ומעקב תשלומים:** הפקת חשבוניות מס עבור תורים ולקוחות ושמירת היסטוריית תשלומים לכל לקוח.
- **ממשק גרפי (GUI) מודרני ונגיש:** עיצוב נקי עם תמיכה בעימוד RTL (מימין לשמאל), פונטים מותאמים אישית ואפשרויות זום (הגדלה והקטנה) של הממשק בקלות.

## 🚀 התקנה והרצה (macOS ו-Windows)

המערכת פועלת באופן עצמאי ומקימה לעצמה את תשתית מסד הנתונים באופן אוטומטי בהרצה הראשונה בעזרת קובץ סכמה (`schema.sql`).
**אין צורך בייבוא מקדים של קובץ `.db`!**

### דרישות קדם:
- Python 3.8 ומעלה
- ספריית `customtkinter` (לממשק הגרפי המודרני)
  
ניתן להתקין את הספריות הנדרשות בעזרת:
```bash
pip install customtkinter
```

### הרצת התוכנה:
1. פתחו את הטרמינל (או ה-Command Prompt) בתיקיית השורש של הפרויקט.
2. הריצו את הפקודה הבאה:

```bash
# למשתמשי Windows:
python __main__.py

# למשתמשי macOS / Linux:
python3 __main__.py
```

עם הפעלת התוכנית ייפתח מסך הפתיחה ולאחריו הממשק הראשי. קובץ הנתונים `appointments.db` ייווצר בתיקייה באופן אוטומטי במידה ואינו קיים.
